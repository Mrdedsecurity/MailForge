📧 MailForge - Intelligent Email Address Generator

**MailForge** is a Python 3 utility that intelligently generates professional email addresses by parsing and processing name inputs. Perfect for researchers, marketers, and anyone needing to build contact lists from names.

![Python Version](https://img.shields.io/badge/python-3.6+-blue.svg)
![Last Updated](https://img.shields.io/badge/last_updated-February_2026-lightgrey.svg)
![Status](https://img.shields.io/badge/status-active-brightgreen.svg)

## ✨ Features

- **Smart Name Parsing**: Automatically extracts first, middle, and last names from various input formats
- **Multiple Email Formats**: Generates professional email addresses in common formats:
  - `first.last@domain.com`
  - `first_last@domain.com`
  - `firstinitiallast@domain.com`
  - `first@domain.com`
  - Customizable formats
- **CSV & Text Output**: Export results in both CSV and plain text formats
- **Domain Customization**: Easily configure target email domains
- **Batch Processing**: Process hundreds of names from input files
- **Lightweight**: No external dependencies, pure Python 3

## 📋 Prerequisites

- **Python 3.6** or higher
- Basic command-line knowledge
